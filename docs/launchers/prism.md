# Prism Launcher

Prism Launcher is popular among avid modded Minecraft players.

**Get it from: [https://prismlauncher.org](https://prismlauncher.org).**

You may find the [Prism Launcher Wiki](https://prismlauncher.org/wiki/) helpful.

## Some Key Settings

Java args go in the `Java` tab of either:
- the general settings window[^1], or
- a specific instances' settings[^2].
