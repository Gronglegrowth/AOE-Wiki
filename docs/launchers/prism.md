# Prism Launcher ![Prism](img/prism_logo.svg){align=right}

Prism Launcher is popular among avid modded Minecraft players.

You can get it from: [https://prismlauncher.org](https://prismlauncher.org).

You may find the [Prism Launcher Wiki](https://prismlauncher.org/wiki/) helpful.

## Key Settings To Know

Prism settings can be found in two windows—a general _Settings_ window that affects all installed game instances, or in each instances' own _Console_ window.

The general _Settings_ window is reached from the [Settings] button of Prism's main window. Each instance's _Console_ window is opened by selecting an instance and then clicking the [Edit] button in the right margin of the main window.

==Memory allocation, java path, and JVM arguments== can all found in the [_Settings_ window's `Java` section](#settings_java), or the `Java` tab of an instance's [_Console_ window's `Settings` section](#console_settings).
